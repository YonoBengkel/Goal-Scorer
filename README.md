# Goal Scorer - Analisis Goal Dataset & Visualisasi

Repositori ini berisi eksplorasi data analisis (EDA), uji statistik inferensia non-parametrik (Kruskal-Wallis & Dunn post-hoc), serta visualisasi eksplanatori berbasis Goal Dataset statistik pemain sepak bola.

## Struktur Direktori

- `uts_takehome_goal_dataset.ipynb` : Jupyter Notebook lengkap berisi tahapan pembersihan data, EDA, uji hipotesis, dan grafik penjelas.
- `data/` : Dataset sumber (`goal_dataset.csv`).
- `grafik/` : Kumpulan grafik hasil analisis (eksploratori dan eksplanatori).
- `hasil/` : Hasil ringkasan analisis statistik dalam format JSON (`hasil_analisis.json`).
